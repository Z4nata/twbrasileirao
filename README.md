# twbrasileirao.com.br

Painel ao vivo das chances do Brasileirão (título, Libertadores, Sul-Americana e Z4) do perfil [@theworstofbrasileirao](https://www.instagram.com/theworstofbrasileirao/).
O navegador busca a tabela e os jogos na API pública da ESPN e simula o fim do campeonato 20 mil vezes a cada atualização (sim.js, num Web Worker).
Estimativa, não previsão.
